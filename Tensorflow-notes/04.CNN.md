# CNN (Convolutional Neural Network)

CNN is the most important deep learning architecture for **image processing**.

Used for:

* Image classification
* Face recognition
* Medical imaging
* Object detection
* Self-driving cars

Examples:

* Cat vs dog classification
* Handwritten digit recognition
* Tumor detection

---

# WHY CNN EXISTS

A normal ANN performs poorly on images because images are huge.

Example:

```text id="d8k7kt"
Image size = 256 × 256 × 3
```

That means:

* 196,608 values

ANN would create too many parameters.

CNN solves this by:

* detecting patterns locally
* sharing filters
* reducing computation

---

# STEP 1 — High-Level CNN Pipeline

Basic CNN flow:

```text id="jq57cq"
Image
↓
Convolution
↓
Activation (ReLU)
↓
Pooling
↓
Flatten
↓
Dense Layers
↓
Prediction
```

This pipeline is VERY important.

You should memorize it.

---

# STEP 2 — Understanding Convolution

CNN uses filters/kernels to detect features.

Examples:

* edges
* corners
* textures
* shapes

Example idea:

```text id="3ev0v1"
Image
↓
Filter slides over image
↓
Feature map created
```

---

# Conv2D Layer

Example:

```python id="p1z1l5"
tf.keras.layers.Conv2D(
    filters=32,
    kernel_size=(3,3),
    activation='relu'
)
```

---

# Important Conv2D Parameters

## 1. Filters

```python id="7y9qyf"
filters=32
```

Means:

* CNN learns 32 feature detectors

More filters:

* better feature extraction
* more computation

---

## 2. Kernel Size

```python id="mjlwmz"
kernel_size=(3,3)
```

Kernel/filter size.

Common:

* 3×3
* 5×5

Example kernel:

\begin{bmatrix}1&0&-1\1&0&-1\1&0&-1\end{bmatrix}

Used to detect vertical edges.

---

## 3. Activation

Usually:

```python id="d5m3bm"
activation='relu'
```

ReLU removes negative values.

f(x)=\max(0,x)

---

# STEP 3 — Pooling Layer

Pooling reduces image dimensions.

Most common:

```python id="4g0p8d"
MaxPooling2D((2,2))
```

Operation:

```text id="j6ivmy"
Take maximum value from small region
```

Benefits:

* smaller computation
* less overfitting
* feature preservation

---

# STEP 4 — Flatten Layer

CNN outputs feature maps.

Dense layers need vectors.

So:

```python id="w4g6tq"
Flatten()
```

converts:

```text id="c1b5yu"
2D feature maps
↓
1D vector
```

# COMPLETE CNN EXAMPLE

## MNIST Handwritten Digits

Dataset:

* 28×28 grayscale images
* digits 0–9

---

# TensorFlow CNN Code

```python id="p8mx7o"
import tensorflow as tf

# Load dataset
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data()

# Normalize
X_train = X_train / 255.0
X_test = X_test / 255.0

# Add channel dimension
X_train = X_train[..., tf.newaxis]
X_test = X_test[..., tf.newaxis]

# Build CNN
model = tf.keras.Sequential([

    tf.keras.layers.Conv2D( 32,(3,3), activation='relu', input_shape=(28,28,1)),

    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Conv2D(64,  (3,3), activation='relu'),

    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Flatten(),

    tf.keras.layers.Dense(128, activation='relu'),

    tf.keras.layers.Dense(10, activation='softmax')
])

# Compile
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# Train
model.fit(X_train, y_train, epochs=5)

# Evaluate
model.evaluate(X_test, y_test)
```
---
✅ Total: 7 layers
2 Convolutional layers (Conv2D)

2 Pooling layers (MaxPooling2D)

1 Flatten layer

2 Dense layers (fully connected, including the output softmax)

* edges

# COMMON CNN PROBLEMS

## 1. Overfitting

Symptoms:

* training accuracy high
* validation accuracy low

Solutions:

* dropout
* augmentation
* more data

---

## 2. Vanishing Gradients

Deep networks struggle to learn.

Solved partly using:

* ReLU
* Batch normalization
